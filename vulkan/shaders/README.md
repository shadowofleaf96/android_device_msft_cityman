`cityman-vk-tri` (and any later Vulkan app) includes these headers from `vulkan/tri/main.cpp` as `#include "../shaders/cityman_tri.vert.spv.h"` and `#include "../shaders/cityman_tri.frag.spv.h"`, then feeds `cityman_tri_vert_spv` / `cityman_tri_frag_spv` to `vkCreateShaderModule` with `codeSize = cityman_tri_*_spv_word_count * sizeof(uint32_t)` and entry point `"main"`; there are no vertex attributes, UBOs, or descriptor sets — the vertex shader writes clip-space `gl_Position` and a location-0 RGB from `gl_VertexIndex` (three hardcoded verts: red / green / blue), and the fragment shader writes location 0 as `vec4(vColor, 1.0)`. Regenerated on the host with `glslc --target-env=vulkan1.0` (SPIR-V 1.0 / Vulkan 1.0). Not a `PRODUCT_PACKAGES` module; HWUI stays GLES.
