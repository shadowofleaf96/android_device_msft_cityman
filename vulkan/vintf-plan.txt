After the gate — exact files to add (device tree only)

1) New fragment (same assemble_vintf wrapper as
   vintf/android.hardware.camera.provider@2.4.xml):

   path: device/msft/cityman/vintf/vulkan.xml

   <manifest version="1.0" type="device">
       <hal format="native">
           <name>vulkan</name>
           <version>1.0</version>
       </hal>
   </manifest>

   Native HAL, name vulkan (hwvulkan module id). Version is
   MAJOR.MINOR only — libvintf parse() rejects three tokens, so
   1.0.3 is illegal here. 1.0.3 stays on the feature XML above.
   No <interface>, no <transport> (same shape as AOSP EGL/GLES
   native HALs). Do not use format="hidl" or name
   android.hardware.vulkan.

2) Wire it in the live VINTF makefile (BoardConfig.mk, one line):

   DEVICE_MANIFEST_FILE += $(DEVICE_PATH)/vintf/vulkan.xml

   assemble_vintf then puts the native vulkan 1.0 HAL into
   /vendor/etc/vintf/manifest.xml.

3) Features: no new PRODUCT_COPY_FILES. Keep level-0 and
   version-1_0_3 only.
